The build stops at "Failed to install dependencies" because npm terminated with an internal error.

1. Pin the Node version Netlify uses to a stable LTS (Node 20) to avoid the npm v10 / Node 22 combination that triggered the npm crash.
   - Add a .nvmrc file at the repository root with the single line:
```text
20
```
   - Commit and push the file, then re-deploy.

   Alternative: set the build environment Node version in netlify.toml (if you prefer):
```toml
[build.environment]
  NODE_VERSION = "20"
```
   After pushing the change, clear Netlify cache and re-deploy.

2. If you prefer to keep Node 22, try forcing a different npm version before installs (less preferred):
   - Add a preinstall script in package.json to downgrade npm to v9:
```json
"scripts": {
  "preinstall": "npm i -g npm@9",
  ...
}
```
   This makes the build use npm 9 for the rest of the install. Commit and push, then re-deploy.

3. Investigate the npm debug log if the above doesn't resolve:
   - The build points to an npm debug log at [line 26](#L26). Inspect that file for the specific stack trace.
   - Run npm install (or npm ci) locally with the same Node version to reproduce and get more info.

Notes and troubleshooting tips
