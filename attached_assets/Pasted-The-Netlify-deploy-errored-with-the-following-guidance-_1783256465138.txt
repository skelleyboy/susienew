The Netlify deploy errored, with the following guidance provided:

Diagnosis

- Relevant log lines:
  - Node engine warnings for Vite: [lines 21–28](#L21-L28) and [lines 67–75](#L67-L75). These show Vite and @vitejs/plugin-react require Node ^20.19.0 or >=22.12.0 while the build is running Node v18.20.8.
  - npm internal warning (likely triggered by engine mismatch): [lines 31–34](#L31-L34) and [lines 78–81](#L78-L81).
  - The immediate build error: the build script runs "tsx script/build.ts" but tsx is not found: [lines 82–85](#L82-L85). This produces the exit code that fails the build ([lines 86–96](#L86-L96)).

Root cause
- Primary immediate failure: the CLI "tsx" binary is missing when running the build, causing "sh: 1: tsx: not found" ([line 84](#L84)). That makes npm exit with code 127.
- Underlying issue: the project uses Vite/@vitejs/plugin-react which require Node >=20.19.0 (or >=22.12.0). The build environment is running Node v18.20.8 ([lines 21–28](#L21-L28), [67–75](#L67-L75)). The Node mismatch likely causes npm instability ("Exit handler never called!") and may prevent some dev tools from being installed or executed as expected.

Solution

1) Verify tsx is in package.json (and committed)
- Open your package.json and confirm tsx appears under dependencies or devDependencies. Example file in your repo: https://github.com/skelleyboy/susienew/blob/main/package.json
- If tsx is missing, add it and commit. From your project root locally run:
```bash
# add tsx as a dev dependency and update lockfile
npm install -D tsx@latest

git add package.json package-lock.json
git commit -m "chore: add tsx dev dependency"
git push
```
- If tsx is already listed, ensure package.json and package-lock.json are committed and pushed.

2) Fix the Node version mismatch on Netlify (required)
- Netlify is currently using Node v18; Vite requires Node >=20.19.0. Update the build environment to use Node 20+.
- Two easy options (pick one and commit/push):
  - Add an .nvmrc file at the repo root with the desired version, e.g.:
    ```text
    20.19.0
    ```
    Commit and push .nvmrc.
  - Or set the NODE_VERSION environment variable in your Netlify site settings to "20.19.0" (or a newer compatible 20.x/22.x) via the Netlify UI.
- More details on changing Node versions on Netlify: https://docs.netlify.com/configure-builds/manage-dependencies/#node-js-and-javascript

3) Redeploy
- After committing tsx (if needed) and adding .nvmrc (or updating the Netlify Node setting), trigger a new deploy. Netlify will pick up the Node version, install dependencies, and tsx should be available for the "npm run build" step.

Notes and troubleshooting
- If you still see "Exit handler never called!" after switching Node, re-trigger a clean build; it is often an npm internal error caused by engine mismatch and should be resolved by using a supported Node version.
- If tsx is present but "not found" persists, ensure the install step actually ran (check logs for "installed" and that no install failures occurred). You can also change the build command to run "npx tsx script/build.ts" as a temporary workaround, but the proper fix is to have tsx listed in package.json and ensure the correct Node version is used.
