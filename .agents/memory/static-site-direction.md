---
name: Static website direction
description: User's product direction for Susie's real estate site and content credibility.
---

The user requested that the whole site become raw HTML, feel real rather than AI-generated, address today's market, and focus on local searches and getting leads.

**Why:** The user wants a credible, searchable real estate business site, not a generic AI-feeling presentation.

**How to apply:** Preserve complete readable HTML and native lead forms without requiring JavaScript. Make useful local content visible to people and crawlers alike. Use sourced, dated market figures and real identity assets rather than unsupported rankings or generated testimonials.

The user supplied three high-quality real estate website references and asked to get as close as possible to that quality, using styles we can execute well and consistent branding and styling.

**Why:** The visual standard is an established professional real estate business, not a generic generated website.

**How to apply:** Carry one recognizable brand through every page, not just the homepage. Use the references for visual quality without copying another agent's identity or fabricating listings and achievements.

The user explicitly corrected that palette and spacing changes were not close enough to the references and that Susie needs a proper logo. They then asked to put her photo at the top, use less introductory and small text, make everything easy to read, design mobile-first, and use nice spacing.

**Why:** The user wants a complete personal brand and an immediately human, readable phone experience, not surface restyling.

**How to apply:** Keep Susie's real photo prominent near the top, concise introductory copy, legible type, comfortable mobile gutters and touch targets, and a proper consistent logo rather than plain initials in a generic badge.

The user specifically requested a 12-column desktop grid.

**Why:** The user wants the alignment and composition discipline seen in the reference sites.

**How to apply:** Align desktop page sections to shared 12-column tracks and common content edges; adapt deliberately to fewer columns on phones.

The user requested removing Golden Realty text from the header and making the main paths lead to contact forms too.

**Why:** The user wants the personal brand in the header and more direct lead capture throughout the site.

**How to apply:** Do not reintroduce brokerage text into the header. Keep appropriate brokerage identification elsewhere. Give marketing pages a native inquiry form and main conversion actions a direct form destination without breaking navigation or phone links.

The user says the site should sound like Susie, using her own bio and client feedback. They requested simple, clear StoryBrand-style copy, no topper text, no small or hard-to-read text, and more mobile side padding.

**Why:** The user repeatedly rejected generic phrasing and overly complicated presentation.

**How to apply:** Keep visitors’ buying or selling needs first, describe how Susie helps, and give a clear form-based next step. Do not add little category labels above headings or photo captions such as “Illustrative home image, not a local listing.” Do not imply generic photography is an actual listing.

The user explicitly said every “Call Susie” action should go to a contact form and there should be no click-to-call links. They requested a floating contact button after scrolling and most recently said “square buttons again.”

**Why:** The user asked.

**How to apply:** All contact actions go to native inquiry forms. Keep phone details non-clickable and prevent mobile automatic telephone linking. Use square-cornered buttons. The user wants the floating “Let’s connect” action only on mobile, after scrolling.

The user requested a hamburger menu on desktop with all her social links, and larger “REAL ESTATE” lettering in the logo.

**Why:** The user asked.

**How to apply:** Keep the hamburger available on desktop and mobile with social and profile links. Also preserve the desktop navigation links and the full logo. The user subsequently refined the logo direction: “REAL ESTATE” should be smaller or thinner than the name, while remaining readable.

The user refined the header reference to compact sans-serif links aligned right and an icon-only hamburger without “Menu” text.

**Why:** The user supplied a specific header reference and asked to match it.

**How to apply:** Keep the expanded menu’s grouped layout, but use clean sans-serif type for the header links and no visible hamburger label. The circular menu toggle is separate from the square main call-to-action buttons.

The user asked to remove the profile logo cards and put the linked logos immediately below the hero.

**Why:** The user asked.

**How to apply:** Use an unboxed logo strip, without an introductory heading or descriptive card text.

The user said to host the logos in this project, not load them from third-party hosts, and to use actual logos for external real estate profiles and social links rather than text alone. They also asked to remove the development-preview form notice.

**Why:** The user asked.

**How to apply:** Keep all visible brand images local. Do not reintroduce the preview banner; preserve explicit errors if a preview submission cannot actually be delivered.

The user stated that black and white are Susie’s brand colors.

**Why:** The user’s explicit brand direction supersedes earlier olive, cream and gold choices.

**How to apply:** Use black, white and neutral grays for the site and Susie’s logo. The user subsequently requested black third-party logos in the expanded menu; keep legible white marks in the dark footer. Use color photography naturally and maintain generous section spacing.

The user requested removing Instagram and TikTok and having page links open at the top.

**Why:** The user asked.

**How to apply:** Do not reintroduce Instagram or TikTok links. Normal page navigation should start at the top; preserve explicit contact-form anchors so inquiry buttons still take visitors to the form.

The user wants Susie's headshot above the fold wherever it makes sense, in a little circle. They separately asked to put the homepage photo back as it was.

**Why:** The user wants a personal presence across the site, while retaining the original homepage portrait treatment.

**How to apply:** Keep small circular introductory headshots on service, community, market and journal pages. Keep the homepage portrait rectangular, and avoid redundant portraits where About and Contact already introduce Susie with a photo.
